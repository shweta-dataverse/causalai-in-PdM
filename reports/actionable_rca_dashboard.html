Counterfactual explanation

Scope & validity of these results

Stated explicitly, because a decision-support tool that hides which numbers are validated is not decision support.

  • Green stages (1-6) are computed from data. Amber stages (7-8) are model-based estimates: C-MAPSS contains no interventional data, so no intervention or counterfactual result here can be checked against ground truth.
  • The causal graph is robustness-validated, not correctness-validated. C-MAPSS ships no ground-truth graph; stability, sensitivity, cross-method agreement and gas-path plausibility are what can be established.
  • Degradation is a latent common driver of all sensors. It is handled by per-engine detrending, which restores the PCMCI stationarity and sufficiency assumptions but removes the trend as a discoverable pathway.
  • C-MAPSS is simulated. Effect magnitudes should be read as relative rankings, not absolute engineering quantities.
  • The composite health indicator is deliberately excluded from the causal variable set: a deterministic function of other nodes violates faithfulness and would corrupt discovery.
  • This pipeline is a prototype. The same interfaces run against causRCA, which provides an expert ground-truth graph and 100 labelled interventions — enabling the validation that C-MAPSS structurally cannot support.
